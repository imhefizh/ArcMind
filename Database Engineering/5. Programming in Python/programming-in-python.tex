\section{Memulai dengan Python}
\subsection{Tentang Python}
Python dinamai setelah acara TV "Monty Python's Flying Circus" dan bukan dari ular piton. Nama ini dipilih karena dianggap singkat dan misterius. Python digunakan dalam aplikasi yang sering kita gunakan, seperti Instagram, Facebook, Google, dan Spotify. Contoh penggunaan Python dalam machine learning termasuk TensorFlow, yang digunakan oleh Airbnb untuk mengklasifikasikan gambar dan oleh perusahaan kesehatan untuk mengklasifikasikan data MRI. Python dianggap mudah digunakan dan sederhana, dengan banyak pustaka (libraries) yang mendukung pengembangan. Memungkinkan pengembang untuk membuat fitur dengan cepat dan melihat hasilnya lebih cepat.

\subsection{Sejarah Pemrograman}
\begin{itemize}
    \item Charles Babbage, pada tahun 1822, menciptakan difference engine untuk mengurangi kesalahan manusia dalam perhitungan.
    \item Babbage juga mengembangkan analytical engine, yang dianggap sebagai dasar dari komputer modern.
    \item Teman Babbage, Ada Lovelace, menulis dokumen yang menjelaskan bagaimana analytical engine dapat melakukan urutan perhitungan, mirip dengan apa yang dilakukan oleh program komputer.
\end{itemize}

\subsection{Dasar-dasar Pemrograman}
\begin{itemize}
    \item Komputer hanya memahami binary code, yang terdiri dari dua digit: 0 dan 1. Binary Code: Sistem bilangan yang hanya menggunakan dua angka, 0 (off) dan 1 (on).
    \item Setiap program yang ditulis harus dikonversi menjadi machine code (kode mesin) agar dapat dipahami oleh komputer. Contoh konversi: Decimal 1 menjadi Binary 1, Decimal 2 menjadi Binary 10.
    \item Komputer menggunakan transistors untuk merepresentasikan binary code. Transistor: Komponen elektronik yang berfungsi sebagai saklar untuk mengontrol aliran listrik.
\end{itemize}

\subsection{Apa itu Pemrograman?}
Pemrograman adalah kemampuan untuk memberikan serangkaian instruksi kepada komputer dalam bahasa yang dapat dipahami.

Pemrograman adalah keterampilan yang dapat diasah dengan latihan. Semakin sering berlatih, semakin baik kemampuan pemrograman seseorang.

Pemrograman juga merupakan keterampilan kreatif, karena ada banyak cara untuk menyelesaikan masalah dengan menulis program.

\subsection{Manfaat Belajar Python}
\begin{itemize}
    \item Mudah Dipelajari: Python memiliki sintaks yang mirip dengan bahasa Inggris, sehingga lebih mudah dibaca dan dipahami.
    \item Produktivitas Tinggi: Dengan Python, pengembang dapat menyelesaikan proyek lebih cepat karena sintaks yang sederhana dan memerlukan lebih sedikit kode dibandingkan dengan bahasa lain seperti C atau Java.
\end{itemize}

\subsection{Aplikasi Python}
\begin{itemize}
    \item Berbagai Platform: Python dapat digunakan di Windows, Mac, dan Linux.
    \item Bidang Penggunaan: Python banyak digunakan dalam pengembangan web, kecerdasan buatan, machine learning, analisis data, dan aplikasi pemrograman lainnya.
\end{itemize}

\subsection{Sintaksis Python dan Pentingnya Spasi}
Menggunakan print("Hello") untuk menghasilkan teks. \verb|print| adalah fungsi yang digunakan untuk menampilkan output ke layar.

\begin{lstlisting}[language=Python, caption={}, captionpos=b]
print("Hello") print("World")
\end{lstlisting}

Jika mencoba menulis dua pernyataan print dalam satu baris tanpa pemisah, akan muncul error \verb|SyntaxError: invalid syntax|. SyntaxError adalah kesalahan yang terjadi ketika kode tidak mengikuti aturan sintaks yang benar.

Mengatasi Error:
\begin{itemize}
    \item Metode Pertama: Memindahkan pernyataan print kedua ke baris baru.
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
print("Hello")
print("World")
    \end{lstlisting}
    \item Metode Kedua: Memisahkan pernyataan dengan titik koma.

          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
print("Hello"); print("World")
    \end{lstlisting}
\end{itemize}

\paragraph{Whitespace adalah} karakter kosong (spasi, tab, newline) yang tidak terlihat tetapi mempengaruhi struktur kode. Menambahkan spasi di sekitar operator tidak menyebabkan masalah, tetapi menambahkan baris baru bisa menyebabkan error. Contohnya seperti ini:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
#any ammount of whitespace on a single line is ok
x     =        1        +        2
\end{lstlisting}
Dan berikut tidak benar:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
x = 1
+ 2

\end{lstlisting}

\paragraph{Indentasi adalah} penggunaan spasi atau tab untuk mengatur blok kode, yang menunjukkan hierarki dan struktur. Penting untuk struktur kontrol seperti if statement.
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
if name == "John":
    print(name)
\end{lstlisting}
Jika indentasi dihapus, akan muncul error \verb|IndentationError: expected an indented block|.

\subsection{Memberi Komentar pada Kode}
Menambahkan komentar ke kode tidak hanya membantu Anda sebagai pengembang, tetapi juga membantu anggota tim lainnya. Komentar sangat berguna untuk menyegarkan ingatan Anda tentang kode yang mungkin telah Anda tulis berbulan-bulan lalu dan Anda mungkin lupa apa tujuannya. Ada beberapa alasan mengapa Anda perlu menambahkan komentar ke berkas kode. Alasannya antara lain:
\begin{itemize}
    \item Menjelaskan tujuan kode.
    \item Memberitahu pengembang bahwa kode tersebut sudah usang.
    \item Menambahkan komentar TODO untuk pekerjaan yang akan diselesaikan nanti.
\end{itemize}
Berikut adalah contoh berbagai jenis komentar yang dapat digunakan.

\subsubsection{Single-line comments}
Penggunaan simbol \verb|#| memberi tahu Python untuk mengabaikan semua yang ada setelah titik ini hingga akhir baris saat ini.
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
# Don't try to Run Me, I'm a comment
x = 10
\end{lstlisting}

\subsubsection{Multi-line comments}
\paragraph{Tanda Kutip Tiga (''' atau """):} Python menggunakan tanda kutip tunggal atau ganda tiga kali untuk membuat komentar multi-baris. Tanda kutip ini biasanya digunakan untuk docstring atau komentar yang mencakup beberapa baris.

\subsubsection{Inline comments}
Simbol \verb|#| memberi tahu Python untuk mengabaikan semua yang ada setelah titik ini hingga akhir baris saat ini. Hal ini memungkinkan komentar ditempatkan di dalam kode itu sendiri. Komentar sebaris sebaiknya digunakan untuk memberikan informasi penting tentang kode yang ditanganinya.

\begin{lstlisting}[language=Python, caption={}, captionpos=b]
x = 1  # Resetting buffer size
\end{lstlisting}

Ingatlah untuk selalu memiliki alasan untuk berkomentar, komentar harus memberikan informasi kepada pembaca dan tidak mengganggu.

\subsection{Pengertian Variabel}
Variabel adalah tempat untuk menyimpan data yang dapat berubah. Dalam Python, Anda dapat mendeklarasikan variabel dengan memberikan nama dan nilai.

Contoh sintaks: X = 10 (di mana X adalah nama variabel dan 10 adalah nilainya).

\subsection{Penamaan Variabel}
Penting untuk memberikan nama yang bermakna agar mudah dipahami oleh programmer lain.

Dua konvensi penamaan yang umum digunakan:
\begin{itemize}
    \item \verb|camelCase|: Huruf pertama dari kata pertama kecil, dan huruf pertama dari setiap kata berikutnya besar. Contoh: \verb|myName|.
    \item \verb|snake_case|`': Semua huruf kecil dengan garis bawah sebagai pemisah. Contoh: \verb|my_name|.
\end{itemize}

\subsection{Mengubah dan Menghapus Variabel}
Anda dapat mengubah nilai variabel yang sudah dideklarasikan dengan cara mendeklarasikannya kembali.
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
a = 10
print(a)  # Output: 10
a = 5
print(a)  # Output: 5
\end{lstlisting}

Untuk menghapus variabel, gunakan perintah del.
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
del a
print(a)  # Akan menghasilkan error: NameError: name 'a' is not defined
\end{lstlisting}

\subsection{Deklarasi Beberapa Variabel}
Anda dapat mendeklarasikan beberapa variabel sekaligus.
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
a, b, c = 1, 2, 3
print(a, b, c)  # Output: 1 2 3
\end{lstlisting}

\subsection{Tipe Data dalam Python}
Tipe data adalah atribut yang terkait dengan data yang memberi tahu sistem komputer bagaimana menginterpretasikan nilainya.

Tipe Data memastikan data dikumpulkan dalam format yang diinginkan dan nilai setiap properti sesuai harapan.

\subsection{Jenis Tipe Data Utama}
\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{./Picts/data-types.png}
    \caption{Pohon Tipe Data}

\begin{itemize}
    \item Numeric: Tipe data ini mencakup:
          \begin{itemize}
              \item Integer: Angka bulat tanpa desimal, misalnya 10 atau -10.
              \item Float: Angka dengan desimal, misalnya 10.5 atau 6.7.
              \item Complex: Angka kompleks yang terdiri dari bagian nyata dan imajiner, misalnya a = 10 + 10j.
          \end{itemize}
    \item Sequence: Tipe data yang berisi satu atau lebih tipe dalam urutan yang teratur, termasuk:
          \begin{itemize}
              \item String: Sekuens karakter yang diapit oleh tanda kutip, misalnya "Hello".
              \item List: Sekuens yang dapat berisi berbagai tipe, diapit oleh tanda kurung siku, misalnya [1, 2, 3].
              \item Tuple: Mirip dengan list, tetapi tidak dapat diubah (immutable), diapit oleh tanda kurung, misalnya (1, 2, 3).

          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
ed = {'a': 22, 'b': 44.4}

          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
is_valid = True

    \item Set: Koleksi tidak terurut dari nilai yang tidak diulang. Contoh:
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
example_set = {1, 2, 3, 4}
\end{lstlisting}
\end{itemize}

\subsection{Deklarasi Strings}
String adalah sekuens karakter yang dikelilingi oleh tanda kutip tunggal (' ') atau ganda (" "). Contoh sintaks: \verb|a = 'hello' atau b = "hello"|.

Encoding adalah proses mengubah karakter menjadi bentuk yang dapat dipahami komputer. Python menggunakan \verb|Unicode| untuk encoding.

\subsection{Mengakses dan Mengubah String}
\begin{itemize}
    \item Indexing: Setiap karakter dalam string dapat diakses menggunakan indeks. Python menggunakan zero-indexing, artinya indeks dimulai dari 0. Contoh: \verb|name[0]| mengakses karakter pertama.
    \item Mengubah Nilai: Anda dapat mengubah nilai string dengan cara menetapkan nilai baru ke variabel. Contoh: name = 'Paul'.
\end{itemize}

\subsection{Fungsi dan Operasi pada Strings}
\begin{itemize}
    \item \verb|len()|: Fungsi untuk memeriksa panjang string. Contoh sintaks: \verb|len(name)| akan mengembalikan jumlah karakter dalam string.
    \item Concatenation: Menggabungkan dua string menggunakan operator +. Contoh: \verb|a + b| akan menggabungkan string a dan b.
\end{itemize}

\subsection{Contoh Penggunaan}
\begin{itemize}
    \item Single Line String: \verb|a = 'this is a single line'|
    \item Multi-Line String: Untuk membuat string yang panjang, gunakan backslash (\verb|\|) di akhir baris. Contoh:
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
b = 'this is a multi-line string example \
that continues here.'
\end{lstlisting}
    \item Output: Menggunakan print() untuk menampilkan string. Contoh: print(a) akan mencetak nilai dari a.

\subsection{Apa itu Typecasting?}
Typecasting adalah proses mengubah satu tipe data menjadi tipe data lain. Dalam Python, ada dua jenis konversi: implicit dan explicit.

\subsection{Implicit Type Conversion}
\paragraph{Implicit Conversion}: Dilakukan secara otomatis oleh compiler Python untuk mencegah kehilangan data. Contoh: mengubah int menjadi float jika nilai yang dimasukkan adalah desimal.

Penting untuk dicatat bahwa Python hanya dapat mengonversi nilai jika tipe data tersebut kompatibel. Misalnya, int dan float kompatibel, tetapi String dan int tidak.

\subsection{Explicit Type Conversion}
\paragraph{Explicit Conversion}: Dilakukan oleh pengembang menggunakan fungsi yang disediakan oleh Python. Beberapa
\begin{itemize}
    \item \verb|str()|: Mengubah tipe data menjadi string. Sintaks: \verb|str(value)|.
    \item \verb|int()|: Mengubah tipe data menjadi integer. Sintaks: \verb|int(value)|.
    \item \verb|float()|: Mengubah tipe data menjadi float. Sintaks: \verb|float(value)|.
\end{itemize}

\subsection{Fungsi Typecasting Lainnya}
\begin{itemize}
    \item \verb|ord()|: Mengembalikan integer yang mewakili karakter unicode yang mendasarinya.
    \item \verb|hex()|: Mengonversi integer menjadi string heksadesimal.
    \item \verb|oct()|: Mengambil integer dan mengembalikan string yang mewakili angka oktal.
    \item \verb|tuple(), set(), list(), dict()|: Fungsi lain untuk mengonversi tipe data.
\end{itemize}

\subsection{Fungsi Input}
Fungsi \verb|input()| digunakan untuk mendapatkan data dari pengguna.

Sintaks: \verb|input("Prompt")|
\begin{itemize}
    \item Contoh: \verb|email = input("Please enter your email address: ")|
    \item Penjelasan: Pengguna akan diminta untuk memasukkan alamat email, yang kemudian disimpan dalam variabel email.
\end{itemize}

\subsection{Fungsi Print}
Fungsi \verb|print()| digunakan untuk menampilkan output ke layar.

Sintaks: \verb|print(value1, value2, ..., sep=' ', end='\n')|
\begin{itemize}
    \item Contoh: \verb|print("Hello", "World", sep=", ")|
    \item Penjelasan: Menampilkan "Hello, World" dengan koma sebagai pemisah.
\end{itemize}

\subsection{Parameter Tambahan untuk Print}
\begin{itemize}
    \item \textbf{sep}: Menentukan pemisah antara objek yang dicetak.
    \item \textbf{end}: Menentukan apa yang dicetak di akhir output (default adalah newline).
    \item \textbf{file}: Menentukan di mana nilai dicetak (default adalah STD out).
    \item \textbf{flush}: Boolean untuk mengatur apakah buffer harus dibersihkan.
\end{itemize}

\subsection{Contoh Penggunaan Input dan Print}
Mengambil dua angka dari pengguna dan mencetak hasil penjumlahannya:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
num1 = int(input("Please enter the first number: "))
num2 = int(input("Please enter the second number: "))
print("The sum is:", num1 + num2)
\end{lstlisting}

Penjelasan: Menggunakan int() untuk mengonversi input menjadi integer sebelum melakukan penjumlahan.

\subsection{Penanganan Tipe Data}
Input dari fungsi input() selalu berupa string.

Sintaks: \verb|type(variable)|
\begin{itemize}
    \item Contoh: \verb|print(type(num1))|
    \item Penjelasan: Menampilkan tipe data dari variabel num1, yang akan menunjukkan bahwa itu adalah string jika tidak dikonversi.
\end{itemize}

\subsection{Penggabungan String}
Menggabungkan dua atau lebih string menggunakan operator \verb|+|.

Contoh:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
first_name = input("Please enter your first name: ")
last_name = input("Please enter your last name: ")
print("Hello, " + first_name + " " + last_name)
\end{lstlisting}

Penjelasan: Menampilkan sapaan dengan nama depan dan belakang yang dimasukkan pengguna.

\subsection{Melihat Lebih Dalam ke Type Casting}
Ada beberapa situasi di mana tipe data dari suatu nilai perlu diubah menjadi tipe data lain.

Proses ini dikenal sebagai casting tipe.

Cara lain yang lebih informal untuk menyebutnya adalah "konversi tipe data".

Contoh paling sederhana dari konversi data dapat dilihat pada perbandingan berikut:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
print(10 == 10)
\end{lstlisting}

Dalam potongan kode di atas, saya bertanya kepada Python apakah angka 10 sama dengan angka 10, dan saya akan mendapatkan nilai boolean True yang dicetak, yang mengonfirmasi bahwa memang keduanya sama.

Bagaimana jika saya melakukan ini?
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
print(10 == 10.00)
\end{lstlisting}

Sekali lagi, nilai boolean True ditampilkan di layar.

Sekarang, Anda mungkin keberatan bahwa, ya, 10 secara teknis tidak sama dengan 10.0 - karena, bisa dibilang, angka pertama adalah bilangan bulat, dan angka kedua adalah bilangan desimal. Anda benar - meskipun ini adalah angka yang sama, mereka memiliki tipe data yang berbeda.

Namun, Python di sini melakukan apa yang disebut "konversi tipe implisit".

Untuk memahami bagaimana ini bekerja, saya akan sedikit mengubah contoh sebelumnya. Alih-alih meminta Python untuk membandingkan kedua angka dan mengembalikan apakah keduanya sama atau tidak, saya akan meminta Python untuk menampilkan hasil penjumlahan kedua angka tersebut.

\begin{lstlisting}[language=Python, caption={}, captionpos=b]
print(10 + 10.0)
\end{lstlisting}

Hasil cetak adalah 20.0.

Hasil ini memungkinkan saya menyimpulkan bahwa saat Python menjalankan operasi yang melibatkan bilangan bulat dan bilangan desimal, ia secara implisit mengubah tipe bilangan bulat menjadi bilangan desimal, lalu menyelesaikan operasi tersebut.

Untuk benar-benar menekankan poin ini, saya dapat memperluas contoh sebelumnya dengan menggunakan fungsi \verb|type()|:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
print(type(10 + 10.0))
\end{lstlisting}

Hasilnya adalah \verb|<class 'float'>|, jadi ini mengonfirmasi kesimpulan saya.

Sekarang saya akan menunjukkan kepada Anda program kecil dalam Python yang bekerja dengan angka:

\begin{lstlisting}[language=Python, caption={}, captionpos=b]
user_num_1 = input('First number is: ')
user_num_2 = input('Second number is: ')
user_sum = user_num_1 + user_num_2
print(user_sum)
\end{lstlisting}

Ketika saya menjalankan program ini, misalnya, saya dapat memasukkan nilai angka pertama sebagai 5, dan nilai angka kedua juga sebagai 5, dengan harapan nilai \verb|user_sum| yang dicetak akan menjadi 10.

Namun, ketika saya melakukan hal itu, angka 55 yang dicetak.

Mengapa ini tidak berfungsi?

Jawabannya cukup sederhana: segala sesuatu yang diketik oleh pengguna oleh Python dikonversi menjadi tipe data string.

Ini berarti, meskipun saya mengetik angka ke dalam dua input tersebut, yang disimpan dalam \verb|user_num_1| dan \verb|user_num_2| sebenarnya adalah string.

Secara efektif, ini sama saja dengan jika saya hanya melakukan ini:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
user_num_1 = "5"
user_num_2 = "5"
user_sum = user_num_1 + user_num_2
print(user_sum)
\end{lstlisting}

Kali ini, hasil cetak dari \verb|user_sum| masih "55", tetapi hal ini tidak mengejutkan.

Untuk membuat kode Python saya berfungsi sesuai yang saya inginkan, saya perlu melakukan konversi tipe secara eksplisit.

Dengan kata lain, saya harus mengubah nilai "5" menjadi nilai 5.

Berikut adalah kode saya yang telah diperbarui:

\begin{lstlisting}[language=Python, caption={}, captionpos=b]
user_num_1 = input('First number is: ')
user_num_2 = input('Second number is: ')
user_sum = float(user_num_1) + float(user_num_2)
print(user_sum)
\end{lstlisting}

Apa yang saya lakukan di sini adalah memastikan bahwa program saya dapat menangani input berupa bilangan float dan tetap berfungsi dengan benar.

Dengan kata lain, saya memastikan bahwa jika pengguna memasukkan nilai float 5.5 sebagai angka pertama dan kedua saat menjalankan kode di atas, outputnya tidak akan menimbulkan kesalahan. Sebaliknya, outputnya akan menjadi 11.0 seperti yang diharapkan.

Bagaimana jika saya memutuskan untuk menampilkan beberapa kata kepada pengguna, memberitahu mereka apa yang terjadi?

Ini adalah upaya untuk melakukannya:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
num_1 = input('First number is: ')
num_2 = input('Second number is: ')
user_sum = float(num_1) + float(num_2)
print("The sum of: " + num_1 + " and " + num_2 + " is " + user_sum)
\end{lstlisting}

Jika saya menjalankan kode di atas, akan muncul kesalahan berikut:

\begin{lstlisting}[language=Python, caption={}, captionpos=b]
    Traceback (most recent call last):
    File "<string>", line 4, in <module>
    TypeError: hanya dapat menggabungkan str (bukan "float") dengan str
\end{lstlisting}

Artinya, saya tidak dapat menggabungkan string dan float seperti itu. Dengan kata lain, meskipun konversi tipe implisit Python berfungsi saat menggunakan operator + pada string dan integer, hal ini tidak berlaku untuk string dan float kecuali Anda secara eksplisit mengonversi float menjadi string.

Perlu diperhatikan juga, Anda juga tidak dapat menggabungkan string dan integer. Hal ini terjadi karena Python menerapkan keamanan tipe, artinya ia memerlukan instruksi eksplisit tentang cara menggabungkan tipe data yang berbeda dalam kasus seperti string dengan integer.

Solusi untuk ini adalah melakukan konversi tipe secara eksplisit, sebagai berikut.

\begin{lstlisting}[language=Python, caption={}, captionpos=b]
n1 = input('First number is: ')
n2 = input('Second number is: ')
user_sum = float(n1) + float(n2)
print("The sum of " + n1 + " and " + n2 + " is " + str(user_sum))
\end{lstlisting}

Kali ini, hasilnya adalah: Jumlah dari 5,5 dan 5,5 adalah 11,0.

\subsection{Operator Matematika}
\begin{itemize}
    \item Addition (+): Digunakan untuk menjumlahkan angka. Contoh sintaks: 2 + 3 menghasilkan 5.
    \item Subtraction (-): Digunakan untuk mengurangkan angka. Contoh sintaks: 3 - 2 menghasilkan 1.
    \item Division (/): Digunakan untuk membagi angka. Contoh sintaks: 35 / 5 menghasilkan 7.0.
    \item Multiplication (*): Digunakan untuk mengalikan angka. Contoh sintaks: 7 * 4 menghasilkan 28.
\end{itemize}

\subsection{Operator Logika}
\begin{itemize}
    \item AND: Memeriksa apakah semua kondisi benar. Contoh: a > 5 and a < 10 hanya benar jika a lebih besar dari 5 dan kurang dari 10.
    \item OR: Memeriksa apakah setidaknya satu kondisi benar. Contoh: a > 5 or b > 10 benar jika salah satu dari a atau b memenuhi kondisi.
    \item NOT: Mengembalikan nilai false jika hasilnya true. Contoh: not (a > 5) akan benar jika a tidak lebih besar dari 5.
\end{itemize}

\subsection{Contoh Penggunaan Operator dalam Pernyataan Kondisional}
Operator biasanya digunakan dengan pernyataan kondisional untuk mengontrol alur program. Contoh: Untuk memberikan diskon di restoran, Anda bisa memeriksa apakah pelanggan adalah anggota program loyalitas dan telah menghabiskan lebih dari \$100.
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
if in_loyalty_program and total_bill > 100:
    total_bill = total_bill - (total_bill * 0.1)
\end{lstlisting}

Contoh Lain:
\begin{itemize}
    \item Mathematical Operators:
          \begin{itemize}
              \item \verb|print(2 + 2)| akan menampilkan 4.
              \item \verb|print(35 / 5)| akan menampilkan 7.0.
          \end{itemize}
    \item Logical Operators:
          \begin{itemize}
              \item \verb|a = True; b = True; if a and b: print("all true")| hanya akan mencetak "all true" jika kedua a dan b adalah true.
          \end{itemize}
\end{itemize}

\subsection{Apa itu Control Flow?}
Control Flow merupakan urutan di mana instruksi dalam program dieksekusi. Program akan mengambil tindakan yang berbeda berdasarkan keputusan yang dibuat.

Dalam Python, ada dua jenis control flow:
\begin{itemize}
    \item Conditional Statements: Seperti \verb|if, else, dan elif|.
    \item Loops: Seperti for loop dan while loop.
\end{itemize}

\subsection{Conditional Statements}
\begin{itemize}
    \item if: Menyatakan bahwa jika kondisi terpenuhi, maka fungsi akan dijalankan.
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
if condition:
    # code to execute
\end{lstlisting}
    \item else: Menjalankan fungsi ketika semua kondisi tidak terpenuhi.
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
else:
    # code to execute if the condition is false
\end{lstlisting}
    \item elif: Menyatakan bahwa jika kondisi sebelumnya tidak terpenuhi, coba kondisi ini.
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
elif another_condition:
    # code to execute if this condition is true
\end{lstlisting}
\end{itemize}

\subsection{Contoh Penggunaan Control Flow}
Dalam contoh restoran, jika total tagihan (\verb|bill_total|) lebih dari 100, maka diskon diterapkan.
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
bill_total = 114
discount1 = 10
if bill_total > 100:
    bill_total = bill_total - discount1
print("Total bill:", str(bill_total))
\end{lstlisting}

Untuk menambahkan diskon untuk tagihan di atas 200, gunakan elif,
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
elif bill_total > 200:
    discount2 = 20
    bill_total = bill_total - discount2
\end{lstlisting}

\subsection{Penggunaan Match Statement}
Match Statement diperkenalkan di Python versi 3.10, match statement memungkinkan penulisan kode yang lebih bersih dan mudah dibaca dibandingkan dengan if statement.
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
match variable:
    case value1:
        # aksi jika variable sama dengan value1
    case value2:
        # aksi jika variable sama dengan value2
    case _:
        # aksi default jika tidak ada yang cocok
\end{lstlisting}

\subsection{Perbandingan dengan if Statement}
If Statement mengharuskan penulisan banyak kondisi dengan if, elif, dan else, yang dapat membuat kode menjadi kompleks.
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
if http_status == 200:
    print("Success")
elif http_status == 404:
    print("Not Found")
else:
    print("Unknown")
\end{lstlisting}

\subsection{Fitur Penting dari Match Statement}
\begin{itemize}
    \item Menggabungkan Beberapa Kondisi: Anda dapat menggunakan operator or untuk menggabungkan beberapa kondisi dalam match statement.
    \item Default Case: Menggunakan \verb|case _| untuk menangani situasi di mana tidak ada nilai yang cocok, mirip dengan else dalam if statement.
    \item Fleksibilitas: Memberikan cara yang lebih bersih untuk menangani banyak kondisi dibandingkan dengan if statement.
\end{itemize}

\subsection{For Loop}
For loop adalah struktur kontrol yang digunakan untuk iterasi melalui sequence (seperti string atau array).

Sintaks:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
for item in sequence:
    # kode yang akan dijalankan
\end{lstlisting}
Contoh:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
str = "looping"
for item in str:
    print(item)
\end{lstlisting}

\subsection{While Loop}
While loop adalah struktur kontrol yang menjalankan blok kode selama kondisi tertentu.

Sintaks:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
while condition:
    # kode yang akan dijalankan
\end{lstlisting}
Contoh:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
count = 0
favorites = ["cake", "ice cream", "cookies", "brownies", "pie"]
while count < len(favorites):
    print("I like this dessert:", favorites[count])
    count += 1
\end{lstlisting}

\subsection{Enumerate Function}
Fungsi \verb|enumerate()| digunakan dalam for loop untuk mendapatkan indeks dan nilai item dalam urutan.

Sintaks:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
for index, item in enumerate(sequence):
    # kode yang akan dijalankan
\end{lstlisting}
Menggunakan enumerate() untuk mencetak indeks dan nilai:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
for idx, item in enumerate(favorites):
    print(idx, item)
\end{lstlisting}
Ini akan mencetak indeks dan nama dessert dari array \verb|favorites|.

\subsection{Catatan Penting terkait Looping}
\begin{itemize}
    \item Infinite Loop: Jika kondisi dalam while loop tidak pernah menjadi false, loop akan terus berjalan tanpa henti. Pastikan untuk mengincrement counter agar tidak terjadi infinite loop.
    \item Indexing: Dalam Python, indeks dimulai dari 0, jadi item pertama memiliki indeks 0 dan item terakhir memiliki indeks n-1, di mana n adalah jumlah item dalam urutan.
    \item Pernyataan \textbf{break} digunakan untuk menghentikan loop, yang pada gilirannya juga menghentikan kondisi else.
    \item Sama seperti perintah break, perintah \textbf{continue} dapat digunakan untuk mengontrol iterasi loop. Perbedaan utamanya adalah perintah continue memungkinkan Anda untuk melewati bagian tertentu dari loop, tetapi kemudian melanjutkan ke bagian sisanya.
    \item Pernyataan \textbf{pass} berfungsi sebagai placeholder, memungkinkan Anda untuk menyertakan blok kode kosong tanpa menyebabkan kesalahan sintaksis. Pernyataan ini tidak melakukan apa-apa dan memungkinkan program untuk melanjutkan eksekusi secara normal.
\end{itemize}

\subsection{Pengertian Nested Loops}
Nested Loop adalah struktur pengulangan di mana satu loop (inner loop) berada di dalam loop lainnya (outer loop). Ini memungkinkan iterasi melalui beberapa koleksi data secara bersamaan.

\subsection{Cara Kerja Nested Loops}
\begin{itemize}
    \item Outer Loop: Loop yang menjalankan iterasi pertama. Setelah itu, ia akan masuk ke inner loop.
    \item Inner Loop: Loop yang berjalan hingga batas yang ditentukan. Setelah selesai, kontrol kembali ke outer loop untuk iterasi berikutnya.
\end{itemize}

\subsection{Contoh Penggunaan Nested Loops}
Misalkan ada dua list dari angka satu hingga sembilan. Dengan menggunakan nested loops, kita dapat menghitung total iterasi:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
count = 0
for i in range(1, 10):  # Outer loop
    for j in range(1, 10):  # Inner loop
        count += 1
print(count)  # Output: 81
\end{lstlisting}

Penjelasan: Outer loop berjalan 9 kali, dan inner loop berjalan 9 kali untuk setiap iterasi outer loop, sehingga total iterasi adalah 9 * 9 = 81.

\subsection{Visualisasi Nested Loops}
Untuk memahami lebih baik, kita bisa mencetak hasil dari setiap iterasi:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
for i in range(10):  # Outer loop
    for j in range(10):  # Inner loop
        print(0, end=' ')
    print()  # New line after inner loop
\end{lstlisting}

Penjelasan: Ini akan mencetak grid 2D dari angka nol.

\subsection{Kompleksitas Waktu}
Time Complexity mengacu pada waktu yang dibutuhkan untuk menjalankan kode. Semakin besar array, semakin lama waktu yang dibutuhkan.

Contoh: Jika outer loop memiliki range 100 dan inner loop 1000, waktu eksekusi akan meningkat.
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
import time
start_time = time.time()
# Code to measure
print("Execution time: ", round(time.time() - start_time, 2))
\end{lstlisting}

\section{Dasar Programming dengan Python}
\subsection{Definisi Fungsi}
\paragraph{Fungsi} adalah sekumpulan instruksi yang dapat digunakan kembali untuk melakukan tugas tertentu. Dalam Python, fungsi dideklarasikan dengan kata kunci \verb|def|.

\subsection{Cara Mendeklarasikan Fungsi}
Sintaks untuk mendeklarasikan fungsi:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
def function_name(parameters):
    # kode yang akan dijalankan
\end{lstlisting}
Contoh:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
def sum(x, y):
    return x + y
\end{lstlisting}

\subsection{Penggunaan Fungsi}
\begin{itemize}
    \item Fungsi dapat menerima parameter dan mengembalikan nilai. Contoh fungsi \verb|print()| yang digunakan untuk menampilkan output ke layar.
    \item Fungsi \verb|input()| digunakan untuk menerima input dari pengguna.
\end{itemize}

\subsection{Contoh Praktis}
\begin{itemize}
    \item Menghitung jumlah pajak dari total tagihan:
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
def calculate_tax(bill, tax_rate):
    return bill * tax_rate / 100
\end{lstlisting}
    \item Memanggil fungsi:
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
total_tax = calculate_tax(175, 15)
print(total_tax)  # Output: 26.25
\end{lstlisting}
\end{itemize}

\subsection{Keuntungan Menggunakan Fungsi}
Fungsi memungkinkan kode menjadi lebih modular dan reusable. Jika ada perubahan, Anda hanya perlu memperbarui fungsi tersebut, dan semua bagian kode yang memanggil fungsi itu akan mendapatkan pembaruan.

\subsection{Jenis-jenis Scope}
\begin{itemize}
    \item \textbf{Local Scope}: Variabel yang dideklarasikan dalam fungsi dan hanya dapat diakses di dalam fungsi tersebut.
    \item \textbf{Enclosing Scope}: Variabel yang dideklarasikan dalam fungsi luar dan dapat diakses oleh fungsi dalamnya.
    \item \textbf{Global Scope}: Variabel yang dideklarasikan di luar semua fungsi dan dapat diakses dari mana saja dalam kode.
    \item \textbf{Built-in Scope}: Variabel dan fungsi yang sudah tersedia di Python, seperti print() dan len().
\end{itemize}

\subsection{Penjelasan dan Contoh}
LEGB merupakan akronim untuk Local, Enclosing, Global, dan Built-in, yang menunjukkan urutan pencarian variabel.
\begin{itemize}
    \item Contoh Global Scope:

          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
my_global = 10
def fn1():
    local_v = 5
    print("Access to global:", my_global)
fn1()  # Output: Access to global: 10
print(local_v)  # Akan menghasilkan error
\end{lstlisting}
          Penjelasan: Variabel \verb|my_global| dapat diakses di dalam fungsi \verb|fn1|, tetapi \verb|local_v| tidak dapat diakses di luar fungsi.
    \item Contoh Enclosing Scope:

          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
def fn1():
    enclosed_v = 8
    def fn2():
        print("Access to enclosed:", enclosed_v)
    fn2()
fn1()  # Output: Access to enclosed: 8
\end{lstlisting}
          Penjelasan: Fungsi \verb|fn2| dapat mengakses variabel \verb|enclosed_v| yang dideklarasikan di dalam fn1.
    \item Built-in Scope:

          Merupakan fungsi dan object yang sudah ada di Python, seperti print() yang dapat diakses dari semua level scope.

          Namun \textbf{reserved keyword} seperti \verb|def, for, if|, etc tidak termasuk built-in scope.
\end{itemize}

\subsection{Apa itu Struktur Data?}
Sejauh ini, Anda hanya menyimpan sedikit data dalam variabel. Ini adalah bilangan bulat, Boolean atau string.

Tetapi apa yang terjadi jika Anda perlu bekerja dengan informasi yang lebih kompleks, seperti kumpulan data seperti daftar orang atau daftar perusahaan?

Struktur data dirancang untuk tujuan ini.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{./Picts/data-structure.png}
    \caption{}
\end{figure}

Struktur data memungkinkan Anda untuk mengorganisir dan mengatur data Anda agar dapat melakukan operasi pada data tersebut. Python memiliki struktur data bawaan berikut: list, dictionary, tuple, dan set. Semua struktur data ini dianggap sebagai struktur data non-primitif, artinya mereka diklasifikasikan sebagai objek.

Selain struktur data bawaan, Python memungkinkan pengguna untuk membuat struktur data mereka sendiri. Struktur data seperti Tumpukan (Stacks), Antrian (Queues), dan Pohon (Trees) semuanya dapat dibuat oleh pengguna.

Setiap struktur data dapat dirancang untuk memecahkan masalah tertentu atau mengoptimalkan solusi yang ada agar menjadi jauh lebih efisien.

\subsubsection{Mutabilitas dan Imutabilitas}
Struktur data dapat bersifat mutable atau immutable. Pertanyaan selanjutnya yang mungkin Anda tanyakan adalah, apa itu mutabilitas? Mutabilitas mengacu pada data di dalam struktur data yang dapat dimodifikasi. Misalnya, Anda dapat mengubah, memperbarui, atau menghapus data saat diperlukan. List adalah contoh struktur data yang dapat diubah. Lawan dari mutabilitas adalah tidak dapat diubah. Struktur data yang tidak dapat diubah tidak akan mengizinkan modifikasi setelah data ditetapkan. Tuple adalah contoh struktur data yang tidak dapat diubah.

\subsection{Pengertian List}
List adalah sebuah urutan dari satu atau lebih tipe data yang berbeda atau serupa. Dalam Python, list adalah array dinamis yang dapat menyimpan tipe data apa pun.

\subsection{Deklarasi List}
Untuk membuat list, gunakan sintaks:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
list1 = [1, 2, 3, 4, 5]  # List berisi angka
list2 = ["A", "B", "C"]   # List berisi string
list3 = ["Hello", 10, True, 3.14]  # List dengan berbagai tipe data
\end{lstlisting}

\subsection{Akses dan Indeks List}
List diindeks mulai dari 0. Untuk mengakses item, gunakan sintaks:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
list1[2]  # Mengakses item ketiga, hasilnya 3
\end{lstlisting}

\subsection{List Bersarang}
Nested List: List yang berisi list lain. Contoh:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
list4 = [1, [2, 3, 4], 5, 6]  # List dengan nested list
\end{lstlisting}

\subsection{Menambahkan Item ke List}
\begin{itemize}
    \item insert(): Menambahkan item pada indeks tertentu.
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
list1.insert(5, 6)  # Menambahkan 6 di akhir list
\end{lstlisting}
    \item append(): Menambahkan item di akhir list
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
list1.append(6)  # Menambahkan 6 di akhir list
\end{lstlisting}
    \item extend(): Menambahkan beberapa item sekaligus
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
list1.extend([6, 7, 8, 9])  # Menambahkan 6, 7, 8, 9
\end{lstlisting}
\end{itemize}

\subsection{Menghapus Item dari List}
\begin{itemize}
    \item pop(): Menghapus item berdasarkan indeks.
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
list1.pop(4)  # Menghapus item kelima
\end{lstlisting}
    \item del: Menghapus item berdasarkan indeks.
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
del list1[2]  # Menghapus item ketiga
\end{lstlisting}
\end{itemize}

\subsection{Iterasi Melalui List}
Untuk mengakses semua item dalam list, gunakan loop:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
for x in list1:
    print(x)  # Mencetak semua nilai dalam list
\end{lstlisting}

\subsection{Apa itu Tuple?}
Tuple adalah struktur data yang dapat menyimpan berbagai jenis data dalam satu variabel. Contoh: Tuple dapat berisi integer, string, double, dan boolean.

\subsection{Cara Mendeklarasikan Tuple}
Untuk mendeklarasikan tuple, gunakan tanda kurung:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
my_tuple = (1, "string", 4.5, True)
\end{lstlisting}

Anda juga dapat mendeklarasikan tuple tanpa tanda kurung, tetapi penggunaan tanda kurung adalah praktik terbaik.

\subsection{Mengakses Elemen dalam Tuple}
Untuk mengakses elemen dalam tuple, gunakan indeks:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
print(my_tuple[1])  # Mengakses elemen dengan indeks 1
\end{lstlisting}

Indeks dimulai dari 0, jadi \verb|my_tuple[1]| akan mengembalikan "string".

\subsection{Menentukan Tipe Tuple}
Untuk mengetahui tipe dari tuple, gunakan fungsi type()
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
print(type(my_tuple))  # Mengembalikan <class 'tuple'>
\end{lstlisting}

\subsection{Metode pada Tuple}
\begin{itemize}
    \item count(): Menghitung jumlah kemunculan nilai dalam tuple.
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
my_tuple.count("string")  # Mengembalikan 1
\end{lstlisting}
    \item index(): Mengembalikan indeks dari nilai yang dicari.
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
my_tuple.index(4.5)  # Mengembalikan 2
\end{lstlisting}
\end{itemize}

\subsection{Perbedaan antara Tuple dan List}
Nilai dalam tuple tidak dapat diubah setelah dideklarasikan. Jika Anda mencoba mengubah nilai, akan muncul error:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
my_tuple[0] = 5  # Akan menghasilkan TypeError
\end{lstlisting}

\subsection{Definisi Sets}
Set adalah sequence yang tidak mengizinkan nilai duplikat dan tidak memiliki urutan.

\subsection{Operasi Dasar pada Sets}
\begin{itemize}
    \item Menambahkan Elemen:

          Sintaks: \verb|set_a.add(6)|
          Definisi: Menambahkan elemen baru ke dalam set.
    \item Menghapus Elemen:

          Sintaks: \verb|set_a.remove(2)| atau \verb|set_a.discard(2)|
          Definisi: Menghapus elemen dari set. remove akan menghasilkan error jika elemen tidak ada, sedangkan discard tidak.
\end{itemize}

\subsection{Operasi Matematika pada Sets}
\begin{itemize}
    \item Union:

          Sintaks: \verb|set_a.union(set_b)| atau \verb\set_a | set_b\
          Definisi: Menggabungkan dua set dan menghilangkan nilai duplikat.
    \item Intersection:

          Sintaks: \verb|set_a.intersection(set_b)| atau \verb|set_a & set_b|
          Definisi: Mengambil elemen yang ada di kedua set.
    \item Difference:

          Sintaks: \verb|set_a.difference(set_b)| atau \verb|set_a - set_b|
          Definisi: Mengambil elemen yang hanya ada di \verb|set_a| dan tidak ada di \verb|set_b|.
    \item Symmetrical Difference:

          Sintaks: \verb|set_a.symmetric_difference(set_b)| atau \verb|set_a ^ set_b|
          Definisi: Mengambil elemen yang ada di salah satu set tetapi tidak di kedua set.
\end{itemize}

\subsection{Catatan Penting Terkait Set}
\begin{itemize}
    \item Tidak Terurut: Set tidak memiliki indeks, sehingga tidak bisa diakses dengan cara seperti \verb|set_a[0]|. Jika dicoba, akan menghasilkan error.
    \item Koleksi Unik: Set hanya menyimpan elemen unik, tidak ada duplikasi.
\end{itemize}

\subsection{Apa itu Dictionary?}
Dictionary adalah struktur data yang menyimpan data dalam bentuk pasangan kunci (key) dan nilai (value). Mirip dengan kamus, di mana Anda mencari kata berdasarkan huruf pertama.

Key-Value Pair: Setiap item dalam dictionary terdiri dari kunci dan nilai yang terkait. Contoh: \verb|{"1": "coffee"}|.

\subsection{Keuntungan Menggunakan Dictionary}
\begin{itemize}
    \item Akses Cepat: Anda dapat mengakses nilai langsung menggunakan kunci, tanpa perlu mencari index seperti pada list. Ini membuatnya lebih cepat dan fleksibel.
    \item Mutable: Nilai dalam dictionary dapat diubah setelah dideklarasikan. Misalnya, Anda dapat mengubah nilai dari "tea" menjadi "mint tea".
\end{itemize}

\subsection{Cara Mengakses dan Memanipulasi Dictionary}
\begin{itemize}
    \item Mengakses Nilai: Untuk mengakses nilai, gunakan sintaks berikut:
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
sample_dictionary = {1: "coffee", 2: "tea"}
print(sample_dictionary[1])  # Output: coffee
\end{lstlisting}
    \item Mengupdate Nilai: Untuk mengubah nilai, gunakan sintaks:
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
sample_dictionary[2] = "mint tea"
\end{lstlisting}
    \item Menghapus Item: Untuk menghapus item, gunakan fungsi del:
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
del sample_dictionary[3]  # Menghapus item dengan kunci 3
\end{lstlisting}
\end{itemize}

\subsection{Iterasi Melalui Dictionary}
Anda dapat menggunakan beberapa metode untuk iterasi, seperti:
\begin{itemize}
    \item Standard Iteration: Menggunakan loop for untuk mengakses kunci.
    \item Items Function: Menggunakan \verb|items()| untuk mendapatkan pasangan kunci-nilai.
    \item Values Function: Menggunakan \verb|values()| untuk mendapatkan semua nilai.
\end{itemize}

\subsection{Contoh Pembuatan dan Penggunaan Dictionary}
\begin{itemize}
    \item Deklarasi Dictionary:
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
my_d = {1: "test", "name": "Jim"}
\end{lstlisting}
    \item Mengakses Kunci:
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
print(my_d[1])  # Output: test
print(my_d["name"])  # Output: Jim
\end{lstlisting}
    \item Menambahkan Kunci Baru:
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
my_d[2] = "Test 2"
\end{lstlisting}
    \item Mengupdate Kunci:
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
my_d[1] = "not a test"
\end{lstlisting}
    \item Menghapus Kunci:
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
del my_d[1]
\end{lstlisting}
\end{itemize}

\subsection{Apa itu args?}
\verb|args| adalah cara untuk mengirimkan sejumlah argumen non-keyword ke dalam fungsi.
Sintaks:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
def function_name(*args):
    # kode untuk memproses args
\end{lstlisting}
Contoh:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
def sum_of(*args):
    total = 0
    for x in args:
        total += x
    return total
\end{lstlisting}
Jika kita memanggil \verb|sum_of(4, 5, 6)|, hasilnya adalah 15.

\subsection{Apa itu kwargs?}
\verb|kwargs| adalah cara untuk mengirimkan argumen keyword ke dalam fungsi, yang memungkinkan kita untuk menggunakan nama parameter.
Sintaks:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
def function_name(**kwargs):
    # kode untuk memproses kwargs
\end{lstlisting}
Contoh:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
def calculate_bill(**kwargs):
    total = 0
    for item, price in kwargs.items():
        total += price
    return round(total, 2)
\end{lstlisting}

\subsection{Struktur data mana yang harus dipilih?}
Bagian yang paling menantang bagi pengembang pemula adalah memahami struktur data mana yang paling sesuai dengan solusi yang dibutuhkan. Setiap struktur data menawarkan pendekatan yang berbeda dalam menyimpan, mengakses, dan memperbarui informasi yang disimpan di dalamnya. Ada banyak faktor yang perlu dipertimbangkan, termasuk ukuran, kecepatan, dan kinerja. Cara terbaik untuk memahami mana yang lebih sesuai adalah melalui contoh.

\subsubsection{Contoh: Daftar Pegawai}
Dalam contoh ini, terdapat daftar karyawan yang bekerja di sebuah restoran. Anda perlu dapat menemukan seorang karyawan berdasarkan ID karyawan mereka, ID numerik berbasis integer. Fungsi \verb|get_employee| berisi loop for untuk mengiterasi daftar karyawan dan mengembalikan objek karyawan jika ID-nya cocok.
Berikut adalah pemilihan struktur data yang salah
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
employee_list = [(12345, "John", "Kitchen"), (12458, "Paul", "House Floor")]

def get_employee(id):
    for employee in employee_list:
        if employee[0] == id:
            return {"id": employee[0], "name": employee[1], "department": employee[2]}

print(get_employee(12458))
\end{lstlisting}
Dalam kode ini, \verb|employee_list| adalah daftar tuple. Kode ini berjalan dengan baik dan akan mengembalikan pengguna Paul, karena ID-nya, 12458, cocok. Tantangannya muncul ketika daftar menjadi lebih besar.

Alih-alih dua karyawan, Anda mungkin memiliki 2000 atau bahkan 20.000. Kode harus mengiterasi daftar secara berurutan hingga angka yang dicari cocok.

Anda dapat mengoptimalkan kode dengan membagi pencarian, tetapi bahkan dengan ini, kinerjanya masih kalah dibandingkan dengan struktur data lain, seperti kamus.
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
employee_dict = {
    12345: {
        "id": "12345",
        "name": "John", 
        "department": "Kitchen"    
    },
    12458: {
        "id": "12458",
        "name": "Paul", 
        "department": "House Floor"    
    }
}

def get_employee_from_dict(id):
    return employee_dict[id];


print(get_employee_from_dict(12458));
\end{lstlisting}

Perhatikan bahwa, dalam blok kode ini, jika Anda mengubah struktur data menjadi kamus, Anda dapat menemukan karyawan tersebut. Perbedaan utamanya adalah Anda tidak perlu lagi mengiterasi daftar untuk menemukannya. Jika daftar membesar menjadi ukuran yang jauh lebih besar, waktu pencarian untuk menemukan karyawan tetap sama.

Ini adalah contoh yang baik tentang cara memilih struktur data yang tepat untuk solusi.

Keduanya bekerja dengan baik, tetapi pertukaran yang perlu dipertimbangkan adalah antara waktu dan skala. Solusi pertama akan bekerja dengan baik untuk jumlah data yang kecil, tetapi kinerjanya menurun seiring dengan pertumbuhan data.

Solusi kedua lebih cocok untuk jumlah data yang besar karena strukturnya memungkinkan waktu pencarian konstan, sehingga jumlah data yang besar dapat diakses dengan kecepatan konstan.

\subsection{Errors}
Error adalah kesalahan dalam kode yang biasanya disebabkan oleh kesalahan manusia, seperti kesalahan pengetikan.

Contoh:
\begin{itemize}
    \item Syntax Error:

          Kesalahan yang terjadi ketika kode tidak mengikuti aturan sintaksis Python. Misalnya, tidak menambahkan titik dua (:) di akhir kondisi.
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
if condition
    # kode
\end{lstlisting}
          Kesalahan ini biasanya ditandai oleh IDE dan menunjukkan lokasi kesalahan.

    \item Indentation Error:

          Kesalahan yang terjadi ketika indentasi tidak konsisten.
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
def function():
    print("Hello")
print("World")  # Jika tidak diindentasikan dengan benar
\end{lstlisting}
          Kesalahan ini menunjukkan bahwa indentasi tidak sesuai dengan yang diharapkan.
\end{itemize}

\subsection{Exceptions}
Exceptions adalah kesalahan yang terjadi saat eksekusi kode dan perlu ditangani oleh pengembang.
Contoh:
\begin{itemize}
    \item ZeroDivisionError: Terjadi ketika mencoba membagi angka dengan nol.

          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
result = 5 / 0  # Ini akan menyebabkan ZeroDivisionError
\end{lstlisting}
          Kesalahan ini menunjukkan bahwa operasi matematika tidak valid.
\end{itemize}

\subsection{Penanganan Exceptions}
Pengembang harus menangani exceptions untuk mencegah aplikasi gagal.

Contoh: Menggunakan blok \verb|try| dan \verb|except| untuk menangani exceptions.
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
try:
    result = 5 / 0
except ZeroDivisionError:
    print("Tidak bisa membagi dengan nol.")
\end{lstlisting}

Blok \verb|try| mencoba menjalankan kode, dan jika terjadi exception, blok \verb|except| akan menangani kesalahan tersebut.

\subsection{Penanganan Exceptions}
\begin{itemize}
    \item \verb|try|: Blok kode yang akan dieksekusi. Jika terjadi kesalahan, eksekusi akan berpindah ke blok except.
    \item \verb|except|: Blok kode yang akan dijalankan jika terjadi exception. Ini memungkinkan kita untuk memberikan pesan kesalahan yang lebih ramah pengguna.
\end{itemize}

\subsection{Mengakses Informasi Exception}
\begin{itemize}
    \item \verb|as e|: Menggunakan alias untuk exception yang terjadi, sehingga kita bisa mencetak informasi lebih lanjut.
    \item \verb|e.__class__|: Mengakses kelas dari exception yang terjadi untuk memberikan informasi lebih spesifik.
\end{itemize}

\subsection{Menangani Beberapa Exceptions}
Chaining except: Kita bisa menambahkan beberapa pernyataan except untuk menangani berbagai jenis exceptions.
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
try:
    result = divide_by(40, 0)
except ZeroDivisionError as e:
    print("Division by zero:", e)
except Exception as e:
    print("An error occurred:", e)
\end{lstlisting}

\subsection{File Handling: open dan close}
\begin{itemize}
    \item open: Digunakan untuk membuka, membaca, dan menulis file. Memerlukan dua argumen: nama file dan mode.
          \begin{itemize}
              \item r: Membuka file untuk dibaca dalam format teks (Default).
              \item rb: Membuka file untuk dibaca dalam format biner.
              \item r+: Membuka file untuk membaca dan menulis.
              \item w: Membuka file untuk menulis (akan menimpa file yang ada).
              \item a: Membuka file untuk menambahkan data.
          \end{itemize}
    \item close: Digunakan untuk menutup koneksi file yang terbuka. Tidak memerlukan argumen.
    \item Membuka file untuk membaca:
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
    file = open("test.txt", "r")
    data = file.readline()
    print(data)
    file.close()
    \end{lstlisting}
\end{itemize}

\subsection{With Statement}
Pernyataan\verb|with open| adalah cara yang lebih baik untuk membuka file karena secara otomatis menutup file setelah selesai digunakan. Ini juga lebih baik dalam menangani kesalahan.
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
with open("test.txt", "r") as file:
    data = file.readline()
    print(data)
\end{lstlisting}

\subsection{Membuat File}
Fungsi \verb|open()| digunakan untuk membuat file baru. Sintaksnya:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
with open("newfile.txt", "w") as file:
\end{lstlisting}

\verb|open()| membuka file dengan mode tertentu. Mode "w" berarti write (tulis), yang \textbf{akan membuat file baru atau menimpa file yang sudah ada}.

\subsection{Menyisipkan Konten}
\begin{itemize}
    \item \verb|write()|: Metode ini digunakan untuk menulis teks ke dalam file. Sintaksnya:
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
file.write("This is a new file created.")
\end{lstlisting}
          \verb|write()| menambahkan string ke file yang dibuka.
    \item \verb|writelines()|: Metode ini digunakan untuk menulis beberapa baris ke dalam file. Sintaksnya:
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
file.writelines(["This is the first line.\n", "This is the second line."])
\end{lstlisting}
          \verb|writelines()| menerima daftar string dan menulisnya ke file. Untuk memisahkan baris, gunakan \\n untuk membuat baris baru.
\end{itemize}

\subsection{Mengganti dan Menambahkan Konten}
Mode Append untuk menambahkan konten tanpa menimpa file yang ada, gunakan mode "a". Sintaksnya:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
with open("newfile.txt", "a") as file:
\end{lstlisting}

Mode "a" (append) memungkinkan penambahan konten ke akhir file yang sudah ada.

\subsection{Menangani Kesalahan (Exception)}
try dan except digunakan untuk menangani kesalahan saat membuat file. Sintaksnya:
\begin{lstlisting}[language=Python, caption={}, captionpos=b]
try:
    with open("sample/newfile.txt", "w") as file:
except FileNotFoundError as e:
    print(f"Error: {e}")
\end{lstlisting}

\subsection{Metode untuk Membaca File}
\begin{itemize}
    \item \textbf{read}:

          Mengembalikan seluruh isi file sebagai string. Anda juga dapat memberikan argumen integer untuk mengembalikan jumlah karakter tertentu.
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
file.read(size)
\end{lstlisting}
          Mengambil semua karakter dari file atau sejumlah karakter yang ditentukan.

    \item readline:

          Mengembalikan satu baris dari file sebagai string. Anda juga dapat memberikan argumen integer untuk mengembalikan sejumlah karakter dari baris tersebut.
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
file.readline(size)
\end{lstlisting}
          Mengambil satu baris dari file, atau sejumlah karakter dari baris pertama jika argumen diberikan.

    \item readlines:

          Membaca seluruh isi file dan mengembalikannya dalam bentuk daftar yang terurut.
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
file.readlines()
\end{lstlisting}
          Mengambil semua baris dari file dan mengembalikannya sebagai daftar, memungkinkan iterasi atau pemilihan baris tertentu.

\end{itemize}

\subsection{Jalur File}
\begin{itemize}
    \item Absolute Path:

          Mengandung informasi lengkap untuk menemukan file, termasuk label drive atau tanda "/" di depan.

          Definisi: Jalur yang menunjukkan lokasi file secara lengkap, terlepas dari direktori saat ini.

    \item Relative Path:

          Tidak mengandung referensi ke direktori root dan biasanya relatif terhadap file yang memanggil.
          Definisi: Jalur yang hanya mencakup informasi yang diperlukan untuk menemukan file dalam direktori kerja saat ini.
\end{itemize}

\subsection{Contoh Penggunaan Open Statement}
\begin{itemize}
    \item Membuka file dengan mode baca:
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
with open('sample.txt', 'r') as file:
    content = file.read()
    print(content)
\end{lstlisting}
          Menggunakan \verb|with open| untuk membuka file, yang secara otomatis menutup file setelah selesai digunakan.

    \item Menggunakan read untuk mencetak isi file:
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
print(file.read())
\end{lstlisting}
          Mencetak seluruh isi file.

    \item Menggunakan readline untuk mencetak baris pertama:
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
print(file.readline())
Mencetak hanya baris pertama dari file.

\end{lstlisting}
    \item Menggunakan readlines untuk mendapatkan daftar baris:
          \begin{lstlisting}[language=Python, caption={}, captionpos=b]
lines = file.readlines()
for line in lines:
    print(line)
\end{lstlisting}
          Mengambil semua baris sebagai daftar dan mencetaknya satu per satu.
\end{itemize}
